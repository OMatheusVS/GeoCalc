# 📐 GeoCalc

🚀 **Calcule áreas de figuras geométricas de forma rápida, simples e intuitiva!**

---

## 🧠 Sobre o projeto

O **GeoCalc** é um aplicativo desenvolvido para facilitar o cálculo de áreas das principais figuras geométricas.  
Ideal para estudantes, profissionais técnicos e qualquer pessoa que precise de resultados rápidos no dia a dia.

✅ Interface simples  
⚡ Cálculos instantâneos  
📱 Design pensado para mobile  

---

## 📊 Funcionalidades

O app permite calcular a área das seguintes figuras:

| Figura       | Símbolo |
|--------------|---------|
| Quadrado   | □       |
| Triângulo  | △       |
| Círculo    | ○       |
| Retângulo  | ▭       |
| Trapézio   | ⏢       |
| Losango    | ◇       |

---

## 📏 Fórmulas utilizadas

### 🟩 Quadrado
**Área:**  
`A = L²`  
📌 *L = lado*

### 🔺 Triângulo
**Área:**  
`A = (b × h) / 2`  
📌 *b = base | h = altura*

### ⚪ Círculo
**Área:**  
`A = π × r²`  
📌 *r = raio*

### ▭ Retângulo
**Área:**  
`A = b × h`  
📌 *b = base | h = altura*

### 🔷 Trapézio
**Área:**  
`A = ((B + b) × h) / 2`  
📌 *B = base maior | b = base menor | h = altura*

### 🔶 Losango
**Área:**  
`A = (D × d) / 2`  
📌 *D = diagonal maior | d = diagonal menor*
